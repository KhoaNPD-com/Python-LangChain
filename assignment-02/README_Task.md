# Prompt-Driven Agent for Generating Work Instructions

## Overview

This project implements a prompt-driven AI agent using Azure OpenAI to automatically generate structured, step-by-step work instructions for automotive manufacturing tasks.

The system transforms high-level engineering task descriptions into clear instructions suitable for factory workers, including:

- Safety precautions
- Required tools and equipment
- Step-by-step procedures
- Acceptance criteria

---

## Objectives

- Automate creation of work instructions for new car models
- Reduce manual documentation effort
- Standardize instruction format across production lines
- Improve clarity and consistency for shop floor operations

# AI-Powered Meeting Summarizer Using Azure OpenAI


## Overview


* [ ] This project builds an AI-powered tool to summarize meeting transcripts
* [ ] Uses Azure OpenAI GPT model for natural language processing
* [ ] Generates concise summaries with key points, decisions, and action items
* [ ] Designed for productivity improvement in fast-paced environments
---
## Objectives

* [ ] Integrate Azure OpenAI GPT models for summarization
* [ ] Process raw meeting transcripts into structured summaries
* [ ] Provide a simple CLI-based application
* [ ] Deliver clear and concise outputs for users

---

## Problem Statement

* [ ] Long meetings are difficult to review and extract key information
* [ ] Manual summarization is time-consuming
* [ ] Need an automated solution to highlight:
  * Key points
  * Decisions
  * Action items

---

## Features

* [ ] Automatic meeting summarization
* [ ] Handles multiple transcripts (batch processing)
* [ ] Structured output format
* [ ] Clean and simple command-line interface
* [ ] Uses environment variables for secure API access

---

## Project Structure

* [ ] `summarizer.py` → main application logic
* [ ] Sample transcripts included in code
* [ ] Console output acts as result logs
